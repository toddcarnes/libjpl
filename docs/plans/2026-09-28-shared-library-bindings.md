# Shared library and language bindings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship libjpl as static and shared libraries under one name in separate install directories, with a generated export header and in-repo C++, Python, C#, and VB.NET bindings.

**Architecture:** Rename the existing `jpl` static target to `jpl_static` and add `jpl_shared` from the same sources with `OUTPUT_NAME "jpl"` on both; generate `jpl_export.h` via `configure_file` and prefix public declarations with `JPL_API`; gate each binding behind its own CMake option so missing toolchains skip cleanly.

**Tech Stack:** C17, CMake 3.20+/CTest, C++17 (header-only wrapper), Python cffi, .NET P/Invoke (C#/VB.NET); PowerShell 5.1 for commands.

**Spec:** `docs/specs/2026-09-28-shared-library-bindings-design.md`

## Global Constraints

- Do not modify `src/erfa/`; use ERFA through internal library code only.
- Library targets use `c_std_17` with `C_EXTENSIONS OFF`.
- MSVC: `/W4 /permissive-`, zero warnings. GCC/Clang: `-Wall -Wextra -Wpedantic`.
- Public headers accumulate Doxygen + decls; use surgical edits so earlier comments survive.
- Public and in-memory Julian dates use `double[2]`; never split an already-rounded scalar.
- Physics constants come from `src/jpl_private.h`, never literals.
- Same `jpl_ephemeris*` must not be shared across threads on the FILE path; bindings document clone/mmap usage.
- Agent commands run under PowerShell 5.1: avoid `&&`/`||`, use `; if ($?) { ... }` for dependent commands, quote paths with spaces, and use `workdir` instead of `cd`.
- MSVC is multi-config: always pass `-C Debug` (or `-C Release`) to ctest.
- Do not stage or commit any files unless the user explicitly asks. Do not merge into `main` without explicit maintainer approval.

```cpp
#pragma once
#include <jpl.h>
#include <stdexcept>
#include <string>
#include <string_view>
#include <vector>

namespace jpl {
class JplError : public std::runtime_error {
public:
    explicit JplError(jpl_status status)
        : std::runtime_error(::jpl_status_string(status)), status_(status) {}
    [[nodiscard]] jpl_status status() const noexcept { return status_; }
private:
    jpl_status status_;
};
inline void throw_if_error(jpl_status status) {
    if (status != JPL_OK) { throw JplError(status); }
}
class Ephemeris {
public:
    explicit Ephemeris(std::string_view path) {
        jpl_ephemeris* raw = nullptr;
        throw_if_error(::jpl_open(std::string(path).c_str(), &raw));
        handle_ = raw;
    }
    ~Ephemeris() { if (handle_ != nullptr) { ::jpl_close(handle_); } }
    Ephemeris(const Ephemeris&) = delete;
    Ephemeris& operator=(const Ephemeris&) = delete;
    Ephemeris(Ephemeris&& other) noexcept : handle_(other.handle_) { other.handle_ = nullptr; }
    Ephemeris& operator=(Ephemeris&& other) noexcept {
        if (this != &other) {
            if (handle_ != nullptr) { ::jpl_close(handle_); }
            handle_ = other.handle_;
            other.handle_ = nullptr;
        }
        return *this;
    }
    [[nodiscard]] const jpl_header& header() const {
        const jpl_header* header = ::jpl_get_header(handle_);
        if (header == nullptr) { throw JplError(JPL_ERROR_ARGUMENT); }
        return *header;
    }
    [[nodiscard]] std::vector<double> constants() const {
        std::vector<double> values(static_cast<std::size_t>(header().constant_count));
        throw_if_error(::jpl_read_constants(handle_, values.data(), values.size()));
        return values;
    }
    void get_state(const double jd_tdb[2], int target, int center, double state[6]) const {
        throw_if_error(::jpl_get_state(handle_, jd_tdb, target, center, state));
    }
    [[nodiscard]] jpl_ephemeris* native_handle() const noexcept { return handle_; }
private:
    jpl_ephemeris* handle_ = nullptr;
};
}  // namespace jpl
```

- [ ] **Step 2: Write the Pythonic wrapper.** `bindings/python/src/libjpl/ephemeris.py`:

```python
"""Pythonic wrapper over the raw cffi bindings."""
from . import _libjpl

_ffi = _libjpl.ffi
_lib = _libjpl._lib


class JplError(Exception):
    """libjpl failure carrying the numeric jpl_status value."""

    def __init__(self, status):
        super().__init__(_ffi.string(_lib.jpl_status_string(status)).decode())
        self.status = int(status)


def _check(status):
    if status != _lib.JPL_OK:
        raise JplError(status)


class Ephemeris:
    """An open DE file. Use as a context manager; closes on exit."""

    def __init__(self, path):
        handle = _ffi.new("jpl_ephemeris **")
        _check(_lib.jpl_open(path.encode("utf-8"), handle))
        self._handle = handle[0]

    def close(self):
        if self._handle is not None:
            _lib.jpl_close(self._handle)
            self._handle = None

    def __enter__(self):
        return self

    def __exit__(self, *args):
        self.close()

    def __del__(self):
        self.close()

    def get_state(self, jd_tdb, target, center):
        jd = _ffi.new("double[2]", [float(jd_tdb[0]), float(jd_tdb[1])])
        out = _ffi.new("double[6]")
        _check(_lib.jpl_get_state(self._handle, jd, int(target), int(center), out))
        return [float(out[i]) for i in range(6)]
```
